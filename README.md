## ✨ Features

### 🎨 Modern Design
- Clean UI with dark theme and custom accent colors.
- Interactive cursor with hover effects (desktop).
- Smooth GSAP animations and typewriter intro.

### 📱 Fully Responsive
- Mobile-first, touch-friendly navigation.
- Smooth cross-browser rendering.

### 🛠️ Interactive Elements
- Auto-advancing certificates slider.
- Hover gallery and interactive blog popups.
- Redesigned modern contact form.

### 🤖 RAG AI Chatbot
- Draggable and interactive floating AI chatbot.
- Connected to a Python/FastAPI backend using Retrieval-Augmented Generation (RAG).
- Answers recruiters' queries in real-time about skills, resume, and experience.

### ⚡ Performance Optimized
- Pure, lightweight HTML/CSS/JS (no heavy frameworks).
- Fast load times and structured SEO tags.

## 🔧 Local Development

### Prerequisites
- Modern web browser and local static server.

### Setup Instructions
1. Clone:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   ```
2. Navigate:
   ```bash
   cd Personal-Portfolio
   ```
3. Run local server and open `index.html` in your browser.

### Project Structure
- `index.html` - Core markup.
- `css/` - Custom stylesheets.
- `js/` - Interactive scripts.
- `rag/` - RAG backend server code (FastAPI/Python).
- `certificate/`, `images/`, `files/` - Assets & media resources.
